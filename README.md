# 🌍 AI Translator

A beginner-friendly Generative AI project that translates text between multiple languages using **Python**, **LangChain**, and **Ollama (Llama 3.2)**.

---

## 🚀 Features

- Translate text between multiple languages
- Interactive command-line interface
- Dynamic prompt generation
- Offline translation using Ollama
- Simple and beginner-friendly

---

## 🛠️ Tech Stack

- Python
- LangChain
- Ollama
- Llama 3.2
